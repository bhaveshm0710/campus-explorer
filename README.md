# Interactive Campus Explorer

A responsive website for discovering campus clubs, upcoming events and student resources, built as a pre-interview project for the Web Development domain of GDG.

All clubs, events and resources are **sample data**, not official college information.

## Features
- Club cards generated from a JavaScript array
- Live search and category filters that work together
- Event cards that reveal more details on click
- Canvas dot-web hero that reacts to the cursor
- Scroll effects: progress bar, fade-in sections, active nav link
- Responsive, semantic HTML, keyboard focus styles, reduced-motion support

## Tech
HTML, CSS and vanilla JavaScript only. No libraries, no build step. Open `index.html` to run.
